# CRT Pro v2: процедурный CRT для DaVinci Resolve

Один и тот же эффект работает на трёх страницах:

| Страница | Что ставится | Где найти в Resolve |
|---|---|---|
| **Edit** | `CRT Pro v2.setting` + ядро `CRTCore.fuse` | Effects Library → Эффекты → Claude → CRT → **CRT Pro v2** |
| **Fusion** | то же ядро как нода | Shift+Пробел → **CRT Core** |
| **Color** | `CRT Pro v2.dctl` | нода → Эффекты → **DCTL** → Claude → CRT Pro v2 |

## Что внутри

- **Процедурное GPU-ядро** (`CRTCore.fuse`). Узор пикселей, строки, сведение,
  выпуклость, углы, виньетка, глубина цвета, мерцание, полоса, зерно, тряска,
  монохром и грейд считаются формулами за 2 прохода. Вся цепочка — 12 нод
  вместо ~130 в 1.0. Свечение и растекание цвета сделаны штатными
  GPU-нодами Fusion.
- **10 узоров пикселей**, 3 режима RGB, **плавный** размер пикселя.
- **Инспектор с вкладками**: Главное / Пиксели / Экран / Цвет / Помехи.
- **Окно пресетов** (кнопка «Окно пресетов» во вкладке «Главное»). Карточки с
  превью, применение в один клик, свои пресеты ★, код в буфер и из буфера,
  переименование и удаление. Свои пресеты общие с 1.0.
- **Замер скорости**: «Главное → Общее → Замер скорости». Время каждого
  прохода выводится в консоль (Рабочая область → Консоль).

## Установка

Распакуй архив куда угодно и дважды кликни `установить CRT 2.0.command`,
затем перезапусти Resolve. CRT Pro 1.0 установщик не трогает.

## Сборка из исходников

`python3 build_crt_pro_2.py` собирает `CRT Pro v2.setting` и `CRTCore.fuse`.
Ядро живёт в `crt_core_template.fuse`, правь его, а не собранный файл.
`python3 gen_data.py build_crt_pro_2.py` обновляет данные окна пресетов.

## Известные ограничения

- Превью пресетов посчитаны ядром на тестовой картинке, а не на твоём клипе.
- В DCTL (страница Color) нет времени и размытия: мерцания, полосы и свечения
  там нет. Свечение добавляется штатным Glow на соседней ноде.
- В Resolve ядро ещё не запускалось, проверена только сборка кода.
