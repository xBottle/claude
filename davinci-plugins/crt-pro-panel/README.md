# CRT Pro Panel (v6): плавающее окно для CRT Pro

Отдельное окно поверх Resolve, которое управляет нодой `CRTPro`. Работает
как второй Инспектор: все изменения идут прямо в ноду, Cmd+Z их отменяет.

## Что есть сейчас

- Все 18 разделов и примерно 100 параметров из `build_crt_pro.py`, с настоящими
  диапазонами и выпадающими списками («Узор», «Режим RGB» и т.д.).
- Сверху ряд из 10 иконок-пресетов. Клик применяет пресет.
- Разделы всегда раскрыты. Сворачивание убрано: в этом UI переключение
  `.Hidden` по клику не перерисовывает окно.
- Прокрутки нет (`ScrollArea` в этом API недоступна), окно растягивается за угол.
- Сетки иконок для «Узора» нет: она ломала раскладку. Картинки лежат в
  `icons/pattern_*.png` на будущее.

## Установка

Скопируй **всю папку** `crt-pro-panel` в
```
~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Comp/
```
Выдели ноду `CRTPro` на странице Fusion, затем
`Рабочая область → Сценарии → Comp → CRT Pro Panel`.

## Файлы

| Файл | Зачем |
|---|---|
| `CRT Pro Panel.lua` | сама панель |
| `crt_pro_data.lua` | разделы, пресеты и диапазоны, сгенерированы из `build_crt_pro.py` |
| `icons/*.png` | иконки пресетов (и узоров, пока не подключены) |
| `gen_data.py` | перегенерирует `crt_pro_data.lua`: `python3 gen_data.py build_crt_pro.py` |
| `make_icons.py` | перегенерирует иконки |
| `*_reference.*` | копии твоих файлов для сверки; рабочие версии лежат у тебя на Mac |

## Красные ошибки в консоли (`ScreenWarp … cannot get Parameter …`)

- Появляются и без панели, при работе в обычном Инспекторе.
- Цепочка всегда начинается с `ScreenWarp`. Это нода Custom (выпуклость и
  цветовая глубина), она считается на процессоре и работает медленнее
  остальных.
- Вероятная причина: Fusion прерывает недосчитанный кадр, когда меняется
  параметр, и все ноды ниже по цепочке пишут в консоль, что не получили вход.
  Эта версия пока не проверена: если ошибки сыплются, когда ничего не трогаешь
  и кадр при этом чёрный, причина в другом.

**Неудачный фикс (откачен).** Я добавлял `GlobalIn/GlobalOut = ±100000000`
четырём маскам (`ScanMask`, `BandMask`, `VigMask`, `CornerMask`). После этого
эффект перестал рендериться совсем. Для масок так делать нельзя. Исходный
`build_crt_pro.py` собирает ровно тот `.setting`, который работал; сверено
побайтно, отличается только пресет «★ Мой CRT».
