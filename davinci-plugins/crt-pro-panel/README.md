# CRT Pro Panel v4 — плавающее окно с иконками (как на референсе)

## Что нового по сравнению с v1-v3

- **Точные данные из твоего генератора.** `crt_pro_data.lua` создан скриптом
  `gen_data.py` прямо из твоего `build_crt_pro.py` (копия лежит рядом как
  `build_crt_pro_reference.py`, только для сверки — рабочий у тебя на Mac).
  Значит структура разделов, диапазоны, выпадающие списки — 1-в-1 с реальной
  нодой, не угадывание через `GetInputList()`.
- **Настоящие выпадающие списки** — Узор, Режим RGB, Режим монохрома и т.д.
  теперь варианты, а не пропускались.
- **Иконки** — сетка из 10 узоров пикселей и 10 пресетов сверху, кликабельные.
  Иконки узоров — процедурные превью тайла (та же логика, что в
  `pattern_tiles()`), иконки пресетов — цветовые карточки по характерному
  цвету пресета (настоящих кадров нет, рендерить их можно только на Mac —
  это отдельный следующий шаг, см. ниже).

## Установка — ВАЖНО: теперь нужна ВСЯ папка

Раньше копировался один `.lua`-файл. Теперь скрипту нужны рядом
`crt_pro_data.lua` и `icons/*.png` — без них он откажется запускаться
(явно скажет, в чём дело, в консоли).

Скопируй **папку `crt-pro-panel` целиком** в:
```
~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Comp/
```
Должно получиться:
```
.../Scripts/Comp/crt-pro-panel/CRT Pro Panel.lua
.../Scripts/Comp/crt-pro-panel/crt_pro_data.lua
.../Scripts/Comp/crt-pro-panel/icons/pattern_0.png ... preset_9.png
```
Пункт в меню Scripts всё равно будет называться "CRT Pro Panel" (по имени
файла), просто он теперь лежит во вложенной папке — так тоже работает.

## Запуск

Как раньше: выдели ноду `CRTPro` на странице Fusion → `Workspace → Scripts →
Comp → CRT Pro Panel`.

## Файлы в папке

| Файл | Зачем |
|---|---|
| `CRT Pro Panel.lua` | сама панель — единственное, что видит Resolve |
| `crt_pro_data.lua` | сгенерированные данные (разделы/пресеты/диапазоны) |
| `icons/*.png` | иконки узоров и пресетов |
| `gen_data.py` | перегенерирует `crt_pro_data.lua`, если поменяешь `build_crt_pro.py` |
| `make_icons.py` | перегенерирует иконки |
| `build_crt_pro_reference.py`, `CRT_Pro_reference.setting`, `validate_crt_pro_reference.lua` | твои файлы-справочники, для сверки в этом репозитории (рабочие версии остаются у тебя на Mac) |

## Если поменяешь параметры в оригинальном build_crt_pro.py

Пришли мне обновлённый файл (или просто перегенерируй сам на Mac:
`python3 gen_data.py build_crt_pro.py` в этой же папке) — панель сразу
подхватит новые диапазоны/разделы при следующем запуске.

## Следующий шаг — настоящие превью пресетов

Сейчас иконки пресетов — цветовые карточки-заглушки, не реальные кадры.
Чтобы сделать по-настоящему (миниатюра = реальный результат применения
пресета к текущему кадру) — нужен скрипт, который на твоём Mac:
1. Применяет пресет к ноде.
2. Рендерит текущий кадр через `comp:Render()` или сохраняет вьюер в файл.
3. Сохраняет как `icons/preset_N.png`.

Это отдельная небольшая задача — скажи, если хочешь её сделать следующим
шагом.
