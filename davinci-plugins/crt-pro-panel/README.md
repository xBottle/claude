# CRT Pro Panel — свой плавающий Inspector

## Что это делает

Отдельное окно (не встроено в правую панель Resolve, можно перетащить куда
угодно на экране), которое:

1. Находит на выделенном клипе ноду CRT Pro.
2. **Само читает список её параметров** — не нужно вручную вписывать все
   129 контролов, скрипт видит реальные имена входов твоего `.setting`.
3. Строит слайдеры/галочки под них.
4. Любое движение в окне сразу применяется к ноде (с Undo, как обычное
   действие в Resolve — Cmd+Z работает).

Это тот же принцип, что у Procedural CRT (сайт-референс): окно живёт
отдельно от Inspector. Разница в том, что сам CRT по-прежнему считается
Fusion-нодами (как ты и делал раньше) — это окно только управляет ими
снаружи, а не переписывает рендер на GPU-шейдер (это был бы уже OFX-путь).

## Шаг 1 — установка файла

Скопируй `CRT Pro Panel.lua` **без переименования** в:

```
~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Comp/
```

Если папки `Scripts/Comp` нет — создай её. Имя файла становится пунктом
меню, поэтому пробелы в имени — это нормально, Resolve их показывает как есть.

## Шаг 2 — перезапуск (если Resolve уже открыт)

Меню скриптов Resolve читает содержимое папки при старте программы, поэтому
если Resolve уже запущен — либо перезапусти его, либо (быстрее) на странице
Fusion открой Console и выполни:

```lua
fusion:UpdateLUTS() -- если не сработает, просто перезапусти Resolve — надёжнее
```

Проще всего — просто перезапустить Resolve один раз после копирования файла.

## Шаг 3 — запуск панели

1. Возьми любой клип с уже применённым эффектом **CRT Pro** (тем самым
   `.setting`, что мы собирали раньше).
2. Выдели этот клип на таймлайне.
3. Открой страницу **Fusion** (вкладка вверху Resolve) — так скрипт увидит
   активный comp. (На странице Edit тоже может сработать, но Fusion — надёжнее,
   там точно инициализирован `fu:GetCurrentComp()`.)
4. Если Fusion открыт — кликни левой кнопкой на саму ноду CRT Pro в графе нод
   (это не обязательно, но так скрипт точно возьмёт именно её, а не гадает).
5. В верхнем меню: **Workspace > Scripts > Comp > CRT Pro Panel**.
6. Появится окно со списком всех параметров — двигай слайдеры, они сразу
   применяются к клипу (смотри превью в плеере Resolve).

## Шаг 4 — что смотреть глазами

- Двигаешь слайдер → в плеере Resolve картинка должна меняться в реальном
  времени (как при движении слайдера в обычном Inspector).
- Открой обычный Inspector этого же эффекта рядом — значения там тоже должны
  обновляться (это одна и та же нода, окно просто второй пульт управления).
- Нажми **«Обновить из ноды»** — если ты поменял что-то в обычном Inspector,
  окно подтянет актуальные значения.
- **Cmd+Z** должен отменять изменения, сделанные через окно, как обычную
  правку в Resolve.

## Если ничего не нашлось ("Нода CRT Pro не найдена")

Скрипт ищет ноду, у которой в имени есть подстрока "crt" (без учёта
регистра). Если ты переименовал ноду при установке эффекта — либо верни
имя с "CRT", либо на Fusion-странице кликни на ноду мышкой перед запуском
скрипта (тогда используется активный выделенный инструмент, имя не важно).

## Если пункта меню Scripts > Comp нет вообще

Значит папка `Fusion/Scripts/Comp/` не существует или файл лежит не там.
Проверь путь через Finder: `Cmd+Shift+G` → вставь путь из Шага 1 → Enter.

## Известные ограничения этого прототипа

- **Разделы не сворачиваются** — в отличие от 18 разделов CRT Pro в
  Inspector, тут пока плоский список всех параметров подряд (первая версия,
  чтобы проверить сам механизм). Дальше можно сгруппировать по названиям
  (например, всё с "Scan" в одну секцию) — на это нужно посмотреть на
  реальные имена входов твоего файла, у меня их нет, я их не выдумывал.
- **Пресетов в этом окне пока нет** — сохранение/загрузка `.crtpreset`
  остались в обычном Inspector (кнопки там уже есть и работают). Добавить
  их сюда — следующий шаг, если общий механизм тебя устроит.
- **Диапазон слайдеров общий (-100..100)** — я не знаю точных
  `INP_MinScale`/`INP_MaxScale` каждого твоего параметра без доступа к
  файлу, поэтому шаг грубый. Если после первого запуска пришлёшь мне вывод
  консоли (`Workspace > Console`) со списком найденных параметров — я
  подставлю точные диапазоны и типы (в т.ч. RGB-цвет для цветовых
  контролов, которые сейчас идут как "other" и не показываются).

## Как прислать мне диагностику, если что-то не так

Открой **Workspace > Console** до запуска скрипта — там будет весь вывод
`print(...)`: сколько параметров найдено, какая нода подключена, ошибки
если что-то не найдено. Скопируй текст оттуда — по нему я поправлю скрипт
не вслепую, а по факту.
