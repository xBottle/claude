# Прототип 1: Fusion UIManager (Lua)

## Что это
Отдельное **плавающее окно**, которое не встроено в Инспектор Resolve — его можно
таскать по экрану, оно живёт поверх интерфейса, как настоящий плагин. Технически —
Lua-скрипт Fusion, использующий `bmd.UIDispatcher` / `fu.UIManager`.

## Плюсы
- Пишется и правится за минуты, без компилятора.
- Полный доступ к Fusion API — можно менять входы любых нод в компе на лету.
- Можно рисовать что угодно: превью пресетов, картинки, вкладки, таблицы.
- Работает уже сегодня на твоём Mac, ничего собирать не надо.

## Минусы
- Технически это скрипт из меню `Workspace > Scripts`, а не «настоящий» плагин
  с автозапуском при выборе клипа — окно не открывается само при накидывании
  эффекта на клип, его нужно запустить руками из меню (это можно смягчить —
  повесить на горячую клавишу или на кнопку в самом Inspector-эффекте, которая
  запускает этот скрипт).
- Рендер самого CRT всё равно делается нодами Fusion (Custom/Merge/Displace) —
  окно только дирижирует значениями, тяжёлую картинку не тянет само.
- Внешний вид — стандартные Qt-виджеты Fusion, не такой отполированный, как
  на sh4rkk.com, но стили (`Font`, `Events`, кастомные `ui:Label` с картинками)
  можно докрутить прилично.

## Как посмотреть
1. Скопируй `CRT Proto Window.lua` в
   `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Comp/`
2. В Resolve: страница Fusion → `Workspace > Scripts > Comp > CRT Proto Window`.
3. Появится отдельное окно с тремя слайдерами. Подписи обновляются живьём.
4. Кнопка «Применить» ищет в текущем компе ноду с именем `CRTProto` и на неё
   давит значения — если ноды нет, просто печатает значения в консоль
   (Workspace > Console), чтобы ты видел, что окно живое.
