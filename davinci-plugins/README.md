# Прототипы: плагин с собственным UI в стиле Procedural CRT

Сравнение двух путей сделать окно, которое идёт **поверх Resolve, не встроено
в Инспектор** — как на https://sh4rkk.com/procedural-crt.

| | `fuse-uimanager-proto/` | `ofx-proto/` |
|---|---|---|
| Технология | Fusion Lua-скрипт, `bmd.UIDispatcher`/`fu.UIManager` | Настоящий OFX-плагин, C++ |
| Рендер CRT | остаётся на Fusion-нодах (как сейчас) | свой процессор/шейдер |
| Компиляция | не нужна | нужен Xcode на Mac |
| Запуск сейчас | да, сегодня же на твоём Mac | только после сборки |
| Похоже на сайт-референс визуально | средне (Qt-виджеты Fusion) | максимально (свой рисованный UI) |
| Трудозатраты дальше | часы-дни | недели |

## Как посмотреть прототипы

**1. Fusion UIManager** — самый быстрый способ увидеть окно уже сегодня:
см. `fuse-uimanager-proto/README.md`.

**2. OFX-плагин** — исходник для сборки на твоём Mac в Xcode:
см. `ofx-proto/README.md`. Эта сессия не может его собрать (Linux-контейнер
без Xcode/Resolve), только пишет код.

## Рекомендация
Начать с прототипа 1 (UIManager) — он даст 80% ощущения "плавающего окна"
за 20% работы, и всю уже готовую логику CRT Pro на нодах можно оставить как
есть, просто заменить/дополнить панель Inspector на своё окно. Прототип 2
(OFX) — это переход на совсем другой продукт: если результат прототипа 1
устроит по внешнему виду, можно не тратить недели на C++.
