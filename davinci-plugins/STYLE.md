# Стиль STORYVERSE — единые правила для всех наборов

Всё визуальное (обложка, иконка в библиотеке, лист пресетов, шапка окна) делается ТОЛЬКО
функциями `storyverse_style.py`. Новый набор = те же функции, меняются лишь кадр и слова.

## Имена и места
- Эффект: «<КОД> Pro» и «<КОД> Pro Demo» (CRT Pro, VHS Pro …). Без точек в имени файла.
- Библиотека Resolve: Effects → STORYVERSE → <КОД> (подпапка на каждый набор).
- Ядро в Fusion: категория STORYVERSE\<КОД>; у демо своя нода «<КОД>CoreDemo».
- Окно пресетов: Scripts/Comp/<код>-pro/; свои пресеты: Fusion/<КОД> Pro User Presets/ (только на машине пользователя, в архив не попадают).

## Картинки
- **Кадр набора** (`store_assets/scene.png`): один кадр на набор, из него — превью всех пресетов, обложка и иконка.
- **Обложка** 1920×1080: кадр с эффектом → мягкое затемнение снизу/слева → «<КОД> PRO» (DejaVu Sans Bold 150, белый)
  слева внизу → подпись одной строкой (40) → короткая белая черта → `S T O R Y V E R S E` справа сверху (26, серый).
  Никаких цветных обводок, неона и лишних надписей.
- **Иконка библиотеки** 104×58: тот же кадр, что на обложке, затемнение снизу, код набора (CRT/VHS) белым слева внизу;
  у демо — метка DEMO в рамке справа сверху. У полной и демо один кадр.
- **Лист пресетов**: превью 320×180, 3 колонки, фон #0E0F14, подпись под превью.
- **Шапка окна** 330×64: название градиентом фиолетовый #9D8CFF → бирюзовый #22D3EE, плашка PRESETS, серая подпись.

## Окно пресетов
- Тёмная тема (#0E0F14), акценты фиолетовый/бирюзовый, кнопки со скруглением 10 px.
- Порядок: шапка → список пресетов с превью → быстрые кнопки набора → поле названия → кнопки → статус → подвал
  «<КОД> PRO · by STORYVERSE». Кнопки и функции окна не трогаем без запроса.

## Демо
- Надпись «STORYVERSE-CORE-<КОД>-PRO.DEMO» внизу по центру (Text+, 3.5% высоты, 55%).
- 3 пресета, 3 крутилки, без окна пресетов и своих пресетов.

## Установка (общая для всех наборов — `storyverse_install.py`)
- В каждом архиве: `Установить (macOS).command`, `Установить (Windows).bat`, `install-linux.sh`,
  **`Инструкция по установке.html`** (установка по шагам + «Если что-то не так»), README, LICENSE.
- Установщик: заголовок набора → одно подтверждение **Enter** → галочки ✓ по шагам → «Готово!» → Enter закрыть.
- Пароль для основной установки НЕ нужен. DCTL (системная папка) — только по вопросу `y`, по умолчанию пропуск.
- После копирования снимаем карантин macOS (`xattr -dr com.apple.quarantine`).
- Блокировку macOS на сам .command без подписи Apple не убрать: в инструкции — правый клик → «Открыть».
  Полное решение — подписанный и нотаризованный .pkg (нужен Apple Developer ID, $99/год).
